------------------------------------------------------------------------------
12. PROJECT OPEN
------------------------------------------------------------------------------

1 read manifest
2 migrate schema
3 open local DB
4 resolve assets
5 restore graph
6 create missing plugin placeholders
7 restore UI layout
8 start engine
9 optionally connect sync

------------------------------------------------------------------------------
13. PROJECT SAVE
------------------------------------------------------------------------------

Commands already persist incrementally.

"Save" creates/marks checkpoint/snapshot.

Avoid one giant blocking save.

------------------------------------------------------------------------------
14. CRASH RECOVERY
------------------------------------------------------------------------------

Journal latest transactions.
On restart:
detect unclean shutdown
offer recovered state
validate asset writes
reopen plugins safely disabled if suspected crash.

------------------------------------------------------------------------------
15. NETWORK DISCONNECT
------------------------------------------------------------------------------

Sync service moves to queued mode.
No domain change.
No transport interruption.
No modal blocking.

------------------------------------------------------------------------------
16. STORAGE DISCONNECT
------------------------------------------------------------------------------

If local replica exists:
continue.

If remote-only:
show unavailable placeholder.

Recording never targets a disappearing remote network path directly unless
explicitly configured and validated; default staging is local.

42. SYSTEM ACCEPTANCE
------------------------------------------------------------------------------

SYS-001 domain imports no Firebase/Supabase SDK.
SYS-002 UI imports no raw database SDK.
SYS-003 audio thread performs no network I/O.
SYS-004 command bus is canonical mutation path.
SYS-005 one transport clock drives all time domains.
SYS-006 provider adapter can be swapped.
SYS-007 server can run without community module.
SYS-008 local app can run without server.
SYS-009 plugin crash isolated.
SYS-010 migrations tested with fixtures.
SYS-011 app can recover unclean shutdown.
SYS-012 storage connector passes common contract suite.
SYS-013 event schemas versioned.
SYS-014 client/server errors use stable codes.
SYS-015 performance budgets exist and are measured.
