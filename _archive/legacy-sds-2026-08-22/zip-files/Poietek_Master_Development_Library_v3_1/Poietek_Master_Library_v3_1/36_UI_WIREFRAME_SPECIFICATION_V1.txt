ACCESSIBILITY
All wireframes require:
logical focus order
keyboard equivalents
labels
high contrast
non-color state indicators.

WIRE-001 Desktop arrange supports browser collapse.
WIRE-002 Inspector changes with selection.
WIRE-003 phone can import/play/split/save.
WIRE-004 tablet supports split view.
WIRE-005 offline status visible but not modal.
WIRE-006 storage/missing asset repair explicit.
WIRE-007 dialogs have keyboard focus trap/escape.
WIRE-008 no competitor-branded public feature names.
