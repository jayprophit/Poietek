LISTENING CALIBRATION

Poietek may store a room/device CalibrationProfile.

Digital signal level is not automatically acoustic SPL.

Only display calibrated SPL if:
measurement device/method provided
calibration workflow completed.

EBU currently provides a -23 LUFS pink-noise reference signal for reference
listening-level workflows.

HEARING SAFETY

Poietek should avoid unexpectedly emitting high-level test tones.
Test generator starts muted/low and requires explicit activation.
