63 — SUPABASE + FIREBASE HYBRID BACKEND
=======================================

RECOMMENDED PROTOTYPE

LOCAL CLIENT
Creative source of truth while working.
IndexedDB/OPFS web.
SQLite/files native.

SUPABASE
Canonical hosted backend:
Auth
Postgres
teams/project directory
comments
rights metadata later
Realtime collaboration relay/presence.

FIREBASE
Non-overlapping optional services:
Hosting for Web App/Website
Cloud Messaging where appropriate
Remote Config / staged feature flags
App Check where appropriate
other Firebase diagnostics/platform services after privacy review.

MEDIA
Local + BYOC.
Supabase free Storage may handle small thumbnails/previews, but is not the large
multitrack media strategy.

WHY NOT DOUBLE WRITE?
Writing every project record to Firestore and Postgres creates:
conflicts
cost
migration problems
two authorization models
two failure paths.

CanonicalBackend interface selects one hosted data authority.

FIREBASE-ONLY TEST MODE
Allowed.
Implement FirebaseBackendAdapter and disable Supabase adapter.

SUPABASE-ONLY MODE
Allowed.

SELF-HOSTED MODE
Later.
