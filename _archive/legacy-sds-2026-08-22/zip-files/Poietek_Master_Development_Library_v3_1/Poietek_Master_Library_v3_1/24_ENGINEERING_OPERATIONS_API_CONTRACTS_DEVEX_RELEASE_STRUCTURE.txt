------------------------------------------------------------------------------
44. V1.5 MASTER SYSTEM RULE
------------------------------------------------------------------------------

Any new feature must answer all six:

1. Where is its canonical data?
2. Which service owns it?
3. How does it work offline?
4. How is it persisted/migrated?
5. How is it exposed in UI?
6. What happens when dependency/provider/device is unavailable?

If any answer is missing, architecture is incomplete.
