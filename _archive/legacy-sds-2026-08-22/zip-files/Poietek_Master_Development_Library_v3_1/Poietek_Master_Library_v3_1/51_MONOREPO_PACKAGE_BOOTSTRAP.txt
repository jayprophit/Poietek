MIGRATION APPROACH
Do not convert to a workspace monorepo in the same commit as the first audio
vertical slice unless tooling remains stable.

Safe sequence:
1. create packages/ directories inside existing Vite repo;
2. use relative imports initially;
3. move App/domain state into packages incrementally;
4. only then introduce npm/pnpm workspace aliases if useful.

WHY
The current repository is still a single Vite application. A giant package
manager/workspace migration would create unrelated breakage before persistence and
real audio are proven.
