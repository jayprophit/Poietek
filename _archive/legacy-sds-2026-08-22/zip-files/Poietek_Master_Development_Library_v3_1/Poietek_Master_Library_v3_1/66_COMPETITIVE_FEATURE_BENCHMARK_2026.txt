POIETEK IMPLEMENTATION BATCH — VERSION 1.10

66 — COMPETITIVE FEATURE BENCHMARK — AUGUST 2026
================================================

TYPE OF TEST

This is a published-capability/design benchmark based on first-party product
documentation, combined with the audited current Poietek/SDS implementation.

It is NOT a lab measurement of competitor latency, DSP transparency or crash rate.

REFERENCE FINDINGS

ABLETON LIVE
Current Live materials reinforce:
Arrangement + Session workflows
audio/MIDI recording
takes/comping
warping
audio-to-MIDI
native instruments/effects
third-party plugins
stem separation.

POIETEK REQUIREMENT
Match those professional DAW/live capabilities, then differentiate with native
hardware mapping, DJ/video/rights/storage integration.

LOGIC PRO
Apple's current Logic material reinforces:
professional Mac/iPad creation
Session Players
Stem Splitter
advanced creation/mixing.

POIETEK REQUIREMENT
Installed tablet workflow cannot be a toy companion.

PRO TOOLS
Current Avid material demonstrates:
professional editing/mixing
Dolby Atmos/internal renderer workflows
ARA/Melodyne-related integration
professional post-production expectations.

POIETEK REQUIREMENT
Professional recording/editing, routing and immersive workflows need measurable
accuracy before five stars.

FL STUDIO
Current Image-Line materials reinforce:
fast pattern/beat workflow
audio recording
stem separation
large native instrument/effect family
plugin support
lifetime-update value proposition.

POIETEK REQUIREMENT
Beatmaking must remain fast and immediate despite broader architecture.

SERATO
Current Serato DJ Pro documents:
4 decks
stems
100+ supported hardware devices
FX
sampler
DVS expansion
club hardware workflows.

REKORDBOX
Current rekordbox documents:
library/set preparation
STEMS
cloud library sync
DVS
video
USB export/library workflows.

DJAY
Current Algoriddim documentation confirms installed operation across:
macOS
iOS/iPad
Windows
Android
with a cross-device account and platform-dependent capabilities.

POIETEK REQUIREMENT
Installed cross-platform creative app behavior is a competitive requirement, not
only a technical preference.

DAVINCI RESOLVE
Current Resolve 21 documentation presents:
editing
color
Fusion VFX/motion graphics
Fairlight audio
media/delivery
multi-user collaboration
in one application.
Fairlight claims up to 2,000 realtime audio tracks in its published feature page.

POIETEK REQUIREMENT
The video/VFX ambition needs a dedicated GPU/proxy/render architecture; a basic
video timeline is not five stars.
