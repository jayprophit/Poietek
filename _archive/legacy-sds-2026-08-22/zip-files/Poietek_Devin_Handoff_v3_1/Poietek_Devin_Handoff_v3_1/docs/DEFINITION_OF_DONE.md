# Definition of Done

A Poietek feature is not done merely because the UI renders.

For applicable features:

- builds/typechecks;
- tests pass;
- persists/reopens;
- undo behavior is defined;
- offline behavior is defined;
- sync behavior is defined;
- errors are visible/actionable;
- accessibility is considered;
- platform capability is honest;
- no secrets/PII leakage;
- no false standards/rights/AI claims;
- benchmark evidence updated.

For audio:
- no fake meters/standards;
- no realtime unsafe operations;
- no silent data loss.

For external providers:
- provider outage has fallback or explicit degraded state.
